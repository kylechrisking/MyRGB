unmodified. MyRGB does not include, link to or modify OpenRGB code: it starts OpenRGB.exe as a
separate program and talks to it over OpenRGB's network SDK protocol (TCP port 6742).

PawnIO (not bundled)
--------------------
Copyright (C) namazso. Driver source: GNU General Public License v2 or later, with an
exception for programs that use it only through its device IO control interface.
https://pawnio.eu

MyRGB does not ship PawnIO. If you choose "Enable RAM / SMBus lighting", the installer downloads
the official PawnIO 2.2.0 installer from https://github.com/namazso/PawnIO.Setup/releases,
checks its SHA-256 and code signature, and runs it. OpenRGB loads PawnIO; MyRGB does not.
